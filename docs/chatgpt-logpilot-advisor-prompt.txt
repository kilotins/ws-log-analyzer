## PROJEKTET: LogPilot
Incident intelligence platform — tar in loggar, parsar, hittar incidenter, förklarar med AI.

Migrerar från en fungerande Streamlit-prototyp (1579 tester, 83 heuristiker, 8 format-plugins) till en riktig plattform.

Jag har laddat upp tre dokument som beskriver hela projektet i detalj:
1. **Dream Architecture** — tech stack, adapter pattern, workspace-modell, AI-pipeline, privacy/GDPR, API-design
2. **Go-To-Market Strategy** — positionering, prissättning, kanaler, lanseringsplan, unit economics
3. **Project Plan & PRD** — V1 scope, byggfaser, databasschema, API-spec, UI-struktur, migrationsplan, roadmap

Läs igenom alla tre dokumenten noggrant innan du svarar. De är den enda källan till sanning för detta projekt.

### Tech stack (beslutad)
- Frontend: React + TypeScript + Tailwind + shadcn/ui
- Backend: Python + FastAPI
- DB: SQLite (lokal) / Postgres (team/SaaS) via adapter pattern
- Auth: Custom OIDC (NoAuth → Local → OIDC), inte Clerk/Auth0
- Deployment: Self-service (laptop → team → enterprise) + SaaS
- AI: Claude/OpenAI/Gemini/lokal, med typed RedactedText gate
- V1 parser: Python (Rust i V2 när skalan kräver det)

### Workspace-modell (beslutad)
Organization → Workspace → Members
- Laptop: auto-skapad "Local" org + "Personal" workspace, ingen login
- Team/Enterprise: OIDC, flera workspaces (dev, devops, secops), RLS-isolering

### Byggfaser (beslutad)
1. Foundation (vecka 1-3): FastAPI + React skelett, DB + adapters, core engine migrering
2. Core Features (vecka 4-7): Upload, parse, analysis view, AI, reports
3. Team & API (vecka 8-11): Auth, workspaces, API keys, ingest API, bakgrundsjobb
4. Polish & Launch (vecka 12-14): Trial flow, Docker Compose, landingsida, docs

### Vad som INTE är V1
Rust engine, ClickHouse, DuckDB, RAG, source code lookup, webhooks ut, Helm, Stripe — allt V2+.
